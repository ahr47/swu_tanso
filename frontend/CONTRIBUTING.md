# 함께 수정하기

## 처음 참여할 때

저장소를 복제한 뒤 폴더를 열고 `npm start`를 실행하세요. 별도 패키지 설치는 필요하지 않습니다.

```sh
git clone <저장소 주소>
cd <저장소 폴더>
npm start
```

## 변경사항 합치기

1. 작업 전에 최신 변경사항을 받습니다: `git pull`.
2. 작업별 브랜치를 만듭니다. 예: `git switch -c fix/item-layout`.
3. README의 파일 표를 참고해 필요한 화면과 스타일을 수정합니다.
4. `npm run check`와 `npm run build`를 실행합니다.
5. 브라우저에서 수정한 화면과 연결 버튼을 확인합니다. 배치 변경은 모바일 크기에서도 확인해주세요.
6. 화면 원본과 생성된 `screens.json`을 함께 커밋하고 브랜치를 올립니다.
7. Pull Request에 수정 내용과 확인한 화면을 적고 팀원이 검토한 뒤 합칩니다.

`screens.json`에서 충돌이 나면 각자의 `pages/*.html` 변경사항부터 합친 뒤 `npm run build`로 다시 생성하세요. 생성 파일을 직접 고쳐 충돌을 해결하지 마세요.

## 수정 시 참고

- 문구·구조는 `pages/`에서, 동작은 JavaScript에서, 배치는 CSS에서 수정합니다.
- `data-name`과 `data-node-id`는 버튼과 입력칸 연결에 사용됩니다. 변경 시 연결 코드도 확인해주세요.
- 원본 디자인의 생성 클래스 전체를 일괄 변경하지 말고 필요한 화면 범위에서 스타일을 적용하세요.
- 계정 정보·토큰·비밀번호·개인 정보를 파일에 넣지 마세요.
- 로그인·마이페이지는 현재 서비스 범위에서 제거되어 있습니다.
